# Published official B1 Galerkin output bundle

This directory is the GitHub-visible output bundle for the official B1,
K=280 Galerkin Pareto experiment. It contains the frozen protocol, source
artifacts, generated candidate and optimizer receipts, exact selection and
cross-evaluation records, the selection seal, all authoritative per-allowance
results, fresh-validation result receipts, and the final summary/report.

The following deterministic, derived arrays are intentionally not versioned:

- `banks/*.npz` (52 MB to 414 MB each; about 1.5 GB total);
- `fresh_validation/reference_fit.npz` and
  `fresh_validation/reference_audit.npz` (111 MB each).

These files exceed GitHub's 100 MB ordinary-file limit and are regenerated by
the sealed workflow from the versioned protocol, source artifacts, checkpoint,
and recorded seeds:

```bash
.venv/bin/python -m experiments.skyrmions_galerkin.official_b1_pareto_run --mode generate-data
.venv/bin/python -m experiments.skyrmions_galerkin.official_b1_pareto_run --mode generate-validation
```

The adjacent JSON manifests preserve the expected identities and provenance of
those derived banks. `fresh_validation/paper_reference_audit.npz` is a compact,
lossless projection of the audit reference containing the exact configuration
nodes, base weights, and seed but not the unused velocity array. It is sufficient
to regenerate the paper visualization; it is not substituted for the full
reference bank by the numerical validation workflow.
