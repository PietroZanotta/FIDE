FIDE visual-element generators

Requirements:
  numpy
  matplotlib

Run all:
  python generate_all.py

Outputs:
  01_system_flow.pdf
  02_measurements.pdf
  03_moment_fiber.pdf
  04_transportability.pdf
  05_design_balance.pdf

All figures are text-free and exported as transparent vector PDFs.
The shared style and helper functions are in fide_style.py.
